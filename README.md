# Honest Enclave Gateway

A browser-based action-puzzle game. You are a spark of truth moving through a chain of enclaves. Collect honesty shards, unlock gateways, evade deceits, and reach the Honest Core.

## How it was built

1. Chose a canvas + vanilla JS stack so it runs on GitHub Pages with no build step.
2. Designed six enclaves as a linear chain, each gated by a shard count requirement.
3. Implemented movement with acceleration/friction, AABB circle-vs-rect collision, and screen bounds.
4. Added deceits (enemies) that patrol and bounce off walls and bounds; contact costs a heart.
5. Collected shards are tracked globally by id so rooms stay cleared after death.
6. Gateways auto-open when the shard requirement is met; otherwise show the needed count.
7. Added Web Audio ambient drone plus SFX for collect, gate, hit, and victory.
8. Added particle bursts, screen shake, fade transitions, HUD, and overlay screens.
9. Tuned visuals with radial gradients, glow (shadowBlur), and an animated starfield.
10. Verified JS syntax with `node --check`.

- Move: WASD or Arrow keys
